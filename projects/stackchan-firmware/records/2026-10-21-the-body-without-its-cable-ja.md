# ケーブルの無い体 — 2026-10-21

⛔ **観察がこの頁の背骨である。プログラムの数は、その周りではなく、その中に証拠として引用される。** デーモンが書いた行は、動いた頭ではない。

**数えたもの。** 機体1台、Mac 1台、アクセスポイント1つ、ソケット1本、そして**どの時点でも USB ケーブルは無い**: 下の測定のあいだずっと `/dev/cu.usb*` は存在せず、`system_profiler SPUSBDataType` に JTAG の機器は並ばなかった。**数えなかったもの:** 画面——⛔ **これのあいだ、部屋に目は無かった**——Wi-Fi の切断、アクセスポイントの再起動、Mac の住所の変化、パケットキャプチャ。下の数はどれも、ログか、基板自身が印字した行から読んだものである。

## 何を尋ねられたか

「線を抜くよ？」——そして「抜いた」——そして「今後は、給電だけ用にどこかのコンセントに繋いでおくね」。

⚠️ **最後の一文は試験ではない。この機体が暮らす配置である。** ⇒ **`/dev/cu.usbmodem101` を開くデーモンには、道が一本も無い。** ここでリンクは改善ではなく、**体に残された唯一の経路である。**

## 何が見えたか

**Mac は、コンソールが無いことと、基板が無いことを、区別できなかった。** 古いジョブは動き続け、行を書き続けた:

```
{"frame": "{...}", "sent": false, "accepted": null, "err": "ENOENT", ...}
```

⛔ **`ENOENT` はホスト自身の無いファイルであり、基板の沈黙ではない**——そしてこの頁まで、ログの中の何もその二つを区別していなかった。

**基板は、待ち受けが消えるたびに、自分から dial し直す。** 入れ替え4回、dial 4回——ポートが戻ってから **0.3 秒から 4 秒**:

```
1792527289.638 accepted 192.168.0.19:50836
1792527566.570 accepted 192.168.0.19:50840
```

**デーモンはいま、それを待ち、体の会話が丸ごとその1本のソケットを渡る。** `bench pos` はリンクの上で答えられ、枠の受理の行は戻り、身振りは流れた——**ケーブルの無いまま、1つの事象の中で全部が起きた**:

```
{"link": "the board dialled in", "peer": "192.168.0.19:50841"}
{"position": [331, 500], "heard": true, "read": "bench: yaw=ok pitch=ok ...", "at": 9971.837653958}
{"neck": "look_up", "from": [331, 500], "to": [80, 500], "poses": 22, "at": 9971.837653958}
{"neck": "look_up", "applied": 22, "late": 21, "held": 27, "at": 9972.958619791}
{"neck": "look_up", "verdict": {"applied": 49, "refused": 0, "clamped": 0}, "at": 9974.254092916}
{"position": [96, 500], "heard": true, "read": "bench: yaw raw 491, angle 9.6 deg (zero 460) ..."}
```

✅ **頭は動いた。** yaw は身振りの前が **33.1°**、後が **9.6°** であり、基板自身の集計——**49 applied**——は、ホストの **22 applied + 27 held** とちょうど等しい。⚠️ **その一致は、0.19.38 の規則が線の上で成り立ったのと同じくソケットの上でも成り立ったことであり、ケーブルの無い状態で確かめられたのは初めてである。**

**そして、線の上で測った待ちは、その旅に耐えなかった。** 最初の2回は、何も聞こえなかった:

```
{"position": null, "heard": false, "read": "", "at": ...}
```

リンク越しの `bench pos` 10回を、リスナの時計で測った:

| 問い | `bench: yaw=ok` が届いた | 位置の行が届いた |
|---|---|---|
| 1 | +0.441 秒 | +0.471 秒 |
| 2 | +0.640 秒 | +0.803 秒 |
| 3 | +0.331 秒 | +0.345 秒 |
| 4 | +0.461 秒 | +0.474 秒 |
| 5 | +0.479 秒 | **+1.045 秒** |
| 6 | +0.723 秒 | +0.861 秒 |
| 7 | +0.299 秒 | +0.418 秒 |

⚠️ **問いは10回送られ、表にあるのは7回である**——最後の3回は記録を閉じる最中に書かれ、答えは残っていない。⛔ **これはこの頁の限界であり、黙った問いの数ではない。**

⛔ **`PORT_WAIT = 0.5` は線に対して測られた数であり、問いについてこない。** ⇒ **`LINK_WAIT = 1.5`** が、リンクの上の探針の上限になった。そして遅い基板は検査になった: `SlowBoard` は 0.7 秒後に答え、位置は読まれる。

**判定の窓も、同じ形で外れた。** 22姿勢を **0.526 秒**で書いた:

```
1792527570.448  sent b'pose 96 500*FB\n'
1792527570.860  recv pose: stream started — goals on the present positions (yaw 565, pitch 780), torque on
1792527570.950  sent b'pose 350 500*24\n'
1792527571.938  recv pose: stream lost after 500 ms — torque released
1792527572.097  recv pose: 22 applied, 0 refused, 0 clamped
```

⛔ **基板自身の集計は、最後の姿勢を書いてから 1.647 秒後に届いた**——`VERDICT_WAIT = 1.5` の外であり、最初の実機の実行はそのために `verdict: null` を残した。⇒ **`LINK_VERDICT_WAIT = 3.0`**。⚠️ **これは測定値ではなく、測定の上に置いた余裕である。**

**22のうち21が、遅れて適用された。** ⛔ **姿勢は着く、予定表は着かない。** 20 ms 刻みの流しは、このリンクが運ぶものではない——そして、ホストも基板もそれを隠さない。

## 何を言っていないか

- ⛔ **リンクは認証されていない。** Mac の 3333 番に届くものは何でも、頭を動かし、LED を灯し、スピーカーを鳴らせる。**体の唯一の線が USB ケーブルだったあいだ、その露出は存在しなかった。** ⚠️ **基板がリンクの上で拒むのは `bench wifi` と `bench dial` であり、枠と姿勢は素通りする。**
- ⛔ **基板の独白はリンクを渡らない。** 渡るのは `Say()` を通る行だけである——`bench:`、`pose:`、`frame:`。`servo: silent for 3 checks…`、`servo: present …`、起動のバナーは `printf` であり、**ケーブルの外では、もう誰も読まない。** ⇒ **このホストは、サーボのバスが黙ったことを、もう知ることができない**——それは 0.19.34 が答えとして建てられた故障である。
- ⛔ **`let go` は一度も記録されていない。** 今日観測された切断はすべてデーモンの入れ替えであり、**切った側が先に死んだ。** 基板が自分から切ったときの行は、まだ無い。
- ⛔ **姿勢が着くことは、予定表が着くことではない。** 22のうち21が遅れた。**頭は、計画が終わった場所にいたのであり、計画が言った時刻にいたのではない。**
- ⛔ **ケーブル無しで生き延びることを、これは測っていない。** 測ったのは、**給電だけの体が、リンク越しにデーモンに動かされ、基板が自分の数で答えたこと**である。⚠️ **Wi-Fi の切断、アクセスポイントの再起動、Mac の住所の変化はどれも未測定**であり、基板が dial する住所は、コンソール無しには言い直せない1つの DHCP リースである。
- ⚠️ **ケーブルを抜いてから、画面を目にした者は居ない。** 顔も、光も、音も、ここでは**基板が受理した枠として**だけ主張され、人が見たものとしては主張されない。
