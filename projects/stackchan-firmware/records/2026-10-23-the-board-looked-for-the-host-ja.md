# 自分のホストを探した基板 — 2026-10-23

⛔ **この頁が記録するのは、動いたリースと、与えられた住所を叩き続けた基板と、dialer が探すことを教わった日である。** ⚠️ **著者がしたことは短く、最初に書く**: USB ケーブルが挿され、言葉は「やろう」だった。**最後の節までは、このセッションが作業するあいだにコンソールとデーモンのログが言ったことである**——⛔ **探索をしているあいだ、首にも光にも画面にも目は訊かれていない**——そして**著者が最後に与えた1語「全部OK」は、言われた場所にそのまま記録され、そこに何かが居るかどうかの主張には変えられていない。**

**数えたもの。** 機体1台、コンソール1本（`/dev/cu.usbmodem1101`——⚠️ **2026-10-21 の記録の `.101` ではない**、そして**この Mac が今日そう名づけた理由は分かっていない**）、アクセスポイント1台、そして `en0` が**2つ**の住所を持つ Mac1台（`192.168.0.106` がリース、`192.168.0.103` がこのセッションの途中で手で足した別名であり、終わりにも残っていた）。**数えなかったもの:** パケットキャプチャ（root が要る）、アクセスポイントの側のログ、そして⛔ **首と光と画面——どれも誰も見ていない。**

## 著者がしたこと

**USB ケーブルを挿した。** そして、この変更（名乗りを持つ基板側の探索と、*誰も来なかった* を言うホスト側の行）を最後まで通すかと訊かれて、**「やろう」**と言った。⚠️ **ケーブル以外の物理的な行動は無い**: 機体はその場に在り、首は一度も動かされていない。

## 故障——デーモンのログが持っていた形

⚠️ **Mac は 04:55 に再起動し、DHCP のリースは `192.168.0.106` で戻ってきた。** 基板の NVS はまだ `192.168.0.103` を名指ししていた。**基板は dial し、何も答えなかった。** その朝デーモンが送ろうとした枠は、こう記録されていた:

```
{"frame": "{\"face\":\"greeting\",\"gesture\":\"look_up\",\"light\":\"warm\",\"sound\":null}",
 "sent": false, "accepted": null, "err": "nobody", "at": 501.860373416, "session": "…"}
```

⛔ **`"err": "nobody"` が言うのは、ホストに接続が無かったことである。基板が試して外したことではない**——そして基板の側には、1行も無かった。**失敗した dial は数を1つ数えるだけだったからである。** **静かなログが、静かな機械として読まれていた。**

## 探索に門を入れる前、基板が言ったこと

✅ **最初の版は、dial が失敗するたびに掃いていた。** その朝、コンソールは `bench dial` にこう答えた:

```
dial: 192.168.0.106:3333, down — 2 dial(s), 0 connect(s)
dial: 402 address(es) swept, 0 found by the sweep
dial: 403 connect attempt(s) failed (last -1), 0 opened without a greeting
dial: 0 attempt(s) had no socket to make
```

⛔ **402 の住所を約7秒で、そしてそのすべてが 0 ms で失敗した。** 理由は、これを見えるようにするために書いた数の中にあった: `connect` は **`errno 118`**、`ENETUNREACH` を返していた。⚠️ **掃き出しは起動時に走り、Wi-Fi はまだ自分自身の住所を持っていなかった**——**経路が無いこととホストが居ないことは、ソケットにとって1つの失敗であり**、その歩きは前者を254回測っていた。

## 門を入れたあと、基板が言ったこと

✅ **規則 `sweep_when(routed, now_us, last_us, every_us)` は `kNoRoute` を最初に置く。** 起動時、同じ日に2度（05:38 と 05:44）:

```
I (197) app_init: Project name:     stackchan-vessel
I (197) app_init: App version:      a465702-dirty
I (197) app_init: Compile time:     Oct 23 2026 05:21:18
reset: reason 11 (usb peripheral)
dial: pointed at 192.168.0.106:3333
dial: 192.168.0.106:3333 gave nothing in 1 ms (errno 118)
dial: no route yet — 192.168.0.106:3333 is not being looked for
dial: 192.168.0.106:3333 gave nothing in 0 ms (errno 118)
dial: no route yet — 192.168.0.106:3333 is not being looked for
wifi: connected ip=192.168.0.100
dial: connected to 192.168.0.106:3333
dial: 192.168.0.106:3333, up — 3 dial(s), 1 connect(s)
dial: 0 address(es) swept, 0 found by the sweep
dial: 2 connect attempt(s) failed (last 118), 0 opened without a greeting
```

- ⚠️ **`reset: reason 11 (usb peripheral)` は、この頁自身が招いたものである**——バナーを読むためにコンソールを開き、開くことがチップをリセットする。**続く2つの断りと接続は、この頁が起こした起動であり、ひとりでに起きた起動ではない。**
- ✅ **`0 address(es) swept` が発見である**: 経路が無ければ、基板はもう住所を疑わず、かつて何も無しに費やしていた歩きを費やさない。
- ⚠️ **門は規則であり、待ちではない**: `no route yet` は2度印字され、**間隔が尽きたからではなく、住所が来たから**止まった。

## 経路の下での掃き出し

✅ **住所が上がってから、誰も持たない住所を指すと:**

```
bench: dial -> 192.168.0.104:3333, kept across a reboot
dial: 192.168.0.104:3333 gave nothing in 3002 ms (errno -1)
dial: found the host at 192.168.0.103:3333 — 2 address(es) past the named one
dial: connected to 192.168.0.103:3333
dial: 2 address(es) swept, 1 found by the sweep
```

- ⚠️ **`errno -1` は時計が尽きたことであり**——3,000 ms の窓——**網が与えた理由ではない。** 2つの綴りを報告で分けているのはそのためである。
- ⚠️ **`2 address(es) past the named one` は、`.104` が先に試されて断られたことを意味する**: 名指しの住所にはそれ自身の 3,000 ms があり、そのあとで歩きが始まる。
- ⛔ **`.103` が答えたのは、このセッションが手で `en0` に足した別名だからである。** ⇒ **歩きは測った; そのために在る事象——動いたホスト——は再現していない。** ⚠️ **`.103` は Mac 自身からの接続には答えない**（そちらでの `connect` は3秒で timeout し、`.106` は即座に答える）; **理由は調べていない。**

## ホストの側

✅ **ホストは名乗り、そして誰も来なかったことを言う。** Mac から待ち受けへ向けて測った:

| 測ったもの | 値 | どこから |
|---|---|---|
| 名乗り | 接続のたび、最初のバイトは `loom\n` | Mac から開いたソケット |
| 受理 | `.106` は **0.001 秒**で受理 | 同じソケット |
| 到着 | `{"link": "the board dialled in", "peer": "192.168.0.100:50406"}` | デーモンのログ、上の起動のあと |
| 枠 | `sent: true, accepted: true` | デーモンのログ |

⛔ **`{"link": "nobody dialled in", "for": N}` の行は、この機械の上で印字されていない。** その日は毎回の起動で基板が来たので、支えているのは試験だけである; ⚠️ **一度も印字されていない行は、機械が確かめていない行である。**

## リンクが戻ったあとで

✅ **リンクはそのあと2つのジェスチャーを運び、著者は見て聞いた。** デーモン自身のソケットへ2行を書いた——`SessionStart`、次に `Stop`——そして部屋は2つとも `acted` と答えた:

| 事象 | 段階 | 顔 | 光 | 音 | 体 |
|---|---|---|---|---|---|
| `SessionStart` | `greeting` | `greeting` | `warm` | `hello` | `look_up` |
| `Stop` | `closing` | `happy` | `warm` | `chime` | `nod` |

**首について基板が言ったこと**——コンソールではなく、リンク越しに、基板自身の行で:

```
look_up  from [56, 431] to [80, 500], 11 poses, 0.200 s
         pose: 39 applied, 0 refused, 0 clamped     (yaw 478, pitch 758)
nod      from [59, 493] to [80, 500], 79 poses, 1.555 s
         pose: 107 applied, 0 refused, 0 clamped    (yaw 479, pitch 778)
```

枠は2つとも `sent: true, accepted: true` で戻った——`{"face":"greeting","gesture":null,"light":"warm","sound":"hello"}` と `{"face":"happy","gesture":null,"light":"warm","sound":"chime"}`——そして部屋はそのあと、事象を持たないまま `breathe` に落ち着いた。

- ⚠️ **予定はまだ位置より後ろに在る**: `look_up` は **11のうち10**、`nod` は **79のうち72** が遅れて適用された——0.19.61 が測った分割のままで、その日の作業では変わっていない。
- ⚠️ **判定の行は途中から読めている**（`tarted — goals on the present positions …`）; その後ろの数は揃っており、2つとも **0 refused** と言っている。

⛔ **著者の言葉は「全部OK」で、3つの問いに与えられた**——首は動いたか、音は鳴ったか、光は見えたか。⚠️ **3つの問いに1語である**: 3つとも良かったと言っており、⛔ **どれがどう見えたか・どう聞こえたかは言っていない**——色も、2つの音のどちらだったかも——**そして画面は問いに含まれていないので、ここには顔についての主張は1つも無い。**

## これが確かめていないこと

- ⛔ **動いたホストを基板が見つけられること。** 見つけた住所は、このセッションがそこに置いたものだった。**走っている基板の下で DHCP のリースが動くことが故障であり、それは再現していない。**
- ⛔ **名乗りの規則が何かを断ること。** `0 opened without a greeting` は 0 以外になったことがない——別のことを答えた候補はまだ無い。
- ⛔ **「nobody」の行が300秒後に印字されること。** この走りの中で、基板を離してそれだけ待ったものは無い。
- ⛔ **以前の版の `connect` の失敗が、なぜすべて 0 ms で返ったのか**——数が印字した `118` より先のことは分かっていない。⚠️ **`118` は `connect` が言ったことであり、局がいつ経路を得たかは、そのあとに続く `wifi: connected` の行から推測している。**
- ⚠️ **見つけた住所が何かを生き延びるか。** それは RAM にだけ在る——リンク越しの `bench dial` は今も断られる——ので、この頁の見つけた住所は次の起動で消えた。**そして掃き出しが見つけたリンクがどれだけ続くかを測った走りは無い。**
- ⛔ **探索のあいだは何も動いていない。** 上の2つのジェスチャーはそのあとに来たもので、デーモンのソケットへ書いた2行から始まっている——**あれは体の記録であり、掃き出しの記録ではない**——そして**画面はいまも見られていない。** この頁の探索の部分は探索と1文の記録であり、体の部分は上の節である。
