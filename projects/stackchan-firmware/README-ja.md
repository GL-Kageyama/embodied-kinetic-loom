# projects/stackchan-firmware/ — 電線の機体側

⛔ **ソースのみ。ビルドしていない。焼いていない。** このリポジトリは機体2へ1バイトも書いたことがなく、このディレクトリはそれを変えない。

**ここに在るもの:** 1つのコマンド枠の読み手と、すべての身振りを断る `apply_command`。**ここに無いもの:** 角度。⛔ **`perk` をサーボ位置に変える数は、どの記録にも無い**——だから正直なファームはそれを持たず、記号を受け取って動かない。

⚠️ **この断りは、誰かが書き忘れた行の代わりではない。** 手元の個体が測られるまで、**これがその行である**（`docs/first-contact-stackchan.md`）。**当て推量の角度は、ソースの中では測定された角度と見分けがつかない**——だから1つも書かない。

## 枠が運ぶもの

**1コマンドにつき JSON 1行**、そしてコマンドは段階の遷移のときだけ届く——流れではない。契約は `schemas/stackchan-command.schema.json` であり、両端がそれを読む。

| 欄 | 値 | 意味 |
|---|---|---|
| `face` | Pet の5つの顔、または `null` | この表情を出す。`null` = 変えない |
| `light` | `off` / `dim` / `breathe` / `warm` / `alert` / `error` | 常に在り、`null` にならない |
| `gesture` | `perk` / `nod` / `turn` / `settle` / `flinch`、または `null` | 首を動かす。`null` = 動かさない |

⛔ **`sound` の欄は無い。** スピーカーはまだ存在しないチャンネルである。

## このソースが、わざと決めないこと

- **角度の表** — 記録も測定も無いので、行も無い;
- **LED の対応** — 12個の並びと色の順は、この個体について記録されていない;
- **画面の描画器** — ここで顔は意味であり、画素ではない;
- **伝送路** — このファイルは1行を読む。その行がどう盤に届くかは電線のフレーミングの問題であり、手元の個体は LAN のサーバではなく、ベンダーのクラウドのクライアントである。

## 最初の書き込みの前に、必ず起きること

⛔ **在庫イメージの復元を1回、そして版を読み戻す。** 安全網は在り、読むことで検証されている。書き込みの経路は、このホストで一度も通されていない。`docs/first-contact-stackchan.md` が、ファイルとハッシュと、何かを押す前に書き留めるべき選択を持っている。

⚠️ **このディレクトリでは何も鳴らない。** ここに C++ の試験は無く、ビルドも無い。`tests/test_stackchan_wire.py` がこれらのリテラルを読み、契約と食い違った日に赤くなる——それが唯一の検査であり、**それは写しを検査していて、機体を検査していない。**
