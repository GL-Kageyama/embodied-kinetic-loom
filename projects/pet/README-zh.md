# projects/pet/ — 画面

**住进 `projects/` 的第一件东西，也是 Pet 之中唯一已经存在的部分。**

⛔ **这是一张脸，仅此而已。** 运动到不了这里——**确定性的核心会计算轨迹，
但还没有任何东西把那份计算接到这个画面上。** **Pet 的身体在 `engine/`，脸在这里。
而两者尚未共用同一只时钟**——**「脸与身体出自同一只时钟」正是设计笔记写下的规则，
也是下面那个决定把这个目录放进仓库内部的理由。**

## 这里记录着两个决定

- **A —— 保留这张脸，并自称「猫」**（2026-09-28，作者）。`expressions.py` 中的五张脸，
  **是从概念文档 §5 逐字抄来的**——**一个字都没有改，连缩进也是。**
  变的是记录，不是图。**为什么「写下名字」本身就是决定，写在 `expressions.py` 里**
  ——**禁止动物形状的论据以「这个 ASCII 是抽象的」为前提，而 `/\_/\` 就是猫的耳朵。**
- **C —— Pet 住在这个仓库内部，`projects/` 之下**（2026-09-28，作者）。
  ⚠️ **这一个是在违背推荐的情况下决定的。** 当时给出的代价是对 `CLAUDE.md` 中一条固定方针的附注，
  **而那条附注还没有付**——**它与 `projects/` 之下第一个调用 LLM 的文件落在同一个提交里。**
  **这个目录里没有那样的文件。脸是确定性的。**

## 五张脸

| 状态 | 脸 | 概念文档为它配的运动 |
|---|---|---|
| `happy` | `( ^.^ )` | small bounce → small bounce → settle |
| `sleepy` | `( -.- )` ＋第四行 `z` | slow downward movement → small sway → still |
| `angry` | `( >.< )` | quick tilt → hold → small corrective movement |
| `curious` | `( o.o )` | small left tilt → center → small right tilt |
| `greeting` | `( ^.^ )` | small forward tilt → return |

⚠️ **最后一行不是笔误：`happy` 与 `greeting` 是同一张脸。**
**它们不是同一个表情**——**把两者区分开的只有运动，别的什么都没有。**
**这是实测，不是主张**（`tests/test_pet_expressions.py`）。
⇒ **去掉身体，这两个状态就变成一个。** **「脸与身体出自同一只时钟」不是样式偏好
——它是从这五张图里出来的。**

## 运行

从仓库根目录:

```
python3 -m projects.pet                # 依次轮转五张，直到 Ctrl-C
python3 -m projects.pet --state sleepy # 只画一张，然后退出
python3 -m projects.pet --sync         # 使用同步更新
```

⚠️ **`--sync` 默认为关闭，这是有意的。**
**你面前的终端是否实现 `CSI ? 2026 h`/`l`，本工房这一侧尚未测量。**
**未经测量的假设，不该成为唯一触碰你终端的那个地方的默认值。**

## 被检查的内容

**`tests/` 对这个目录主张四件事**——三个文件，与其余测试一起运行:

- **一帧就是一次 write**——**而这是安全问题，不是速度问题。**
  `frame()` 把同步更新的开始与结束**放在同一个字符串里**返回，
  因此只写一次的调用方不可能把这一对留在打开状态。
  **`close()` 发出的第二个 `SYNC_END` 是对 write 被截断时的救助，它是幂等的。**
- **帧的形状不随状态改变**——五个状态的箱子都是 8 列 × 4 行，
  所以重画时不会残留上一帧的行。
- **没有比一列更宽的字符**——**本工房的文档是 CJK。**
  脸里混进一个全角字符，**屏幕上图会移位，而 `len()` 什么都不会说。**
- **`projects/` 不 import 任何会变化的东西**——与 `engine/` 相同的禁止清单，
  取自 `tools/purity.py`。⛔ **`__main__.py` 被排除清单点名，而排除本身也被检查**
  ——**入口是这个仓库唯一可以 import `time` 的地方，
  因为循环从调用方接收它的时钟。**

⚠️ **最后一条并不能让这个目录和 `engine/` 一样强。** 它看的只是 import。

## 这里没有的东西

- **没有运动。** `engine/` 会计算它。**没有东西把两者连起来。**
- **没有与身体共用的时钟。** 画面画出状态，**并不让它动。**
- **没有 LLM。** 何时何地改变，见上面的决定 C。
