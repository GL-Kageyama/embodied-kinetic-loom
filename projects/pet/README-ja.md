# projects/pet/ — 画面と運動

**`projects/` に住む最初のものであり、Pet のうちで存在している唯一の部分である。**

**核心と画面は、1つの状態について繋がった。** `motions/greeting.json` はセッションが書いた `Motion Intent` であり、**`motion.py` がそれを受理し、軌道を計算し、門を通して Mock へ送る**——**そして、同じループの最初の刻みの中で顔を描く。** それが*顔と身体は一つの時計から*であり、**説明ではなく検査で押さえてある。**

⛔ **身体は Mock のものであって、機体のものではない。** ここはポートを開かない。**シリアル層は、依然として機体が握っている唯一の部分である。**

## 記録されている決定が2つある

- **A — 顔を保ち、「猫」と名乗る**（2026-09-28、著者）。`expressions.py` の5つの顔は、
  **概念文書 §5 から逐語で写した**——**1文字も変えていない。字下げも含めて。**
  変わったのは図ではなく記録である。**なぜ名を書くことが決定そのものなのかは `expressions.py` に在る**
  ——**動物の形を禁じた論は「この ASCII は抽象的である」を前提にしており、`/\_/\` は猫の耳である。**
- **C — Pet はこのリポジトリの内側、`projects/` の下に住む**（2026-09-28、著者）。
  ⚠️ **これは推奨に反して決まった。** 示された代価は `CLAUDE.md` の固定方針への但し書きであり、
  **その但し書きはまだ払われていない**——**`projects/` の下で LLM を呼ぶ最初のファイルと同じコミットで入る。**
  **このディレクトリに、そのファイルは無い。**

## 5つの顔

| 状態 | 顔 | 概念文書が組み合わせている運動 |
|---|---|---|
| `happy` | `( ^.^ )` | small bounce → small bounce → settle |
| `sleepy` | `( -.- )` ＋4行目 `z` | slow downward movement → small sway → still |
| `angry` | `( >.< )` | quick tilt → hold → small corrective movement |
| `curious` | `( o.o )` | small left tilt → center → small right tilt |
| `greeting` | `( ^.^ )` | small forward tilt → return |

⚠️ **最後の行は書き間違いではない。`happy` と `greeting` は同じ顔である。**
**同じ表情ではない**——**2つを分けているのは運動だけであり、それ以外に何も無い。**
**これは主張ではなく実測である**（`tests/test_pet_expressions.py`）。
⇒ **身体を落とせば、この2つの状態は1つになる。** **「顔と身体は一つの時計から」は
様式の好みではない——この5つの図から出てくる。** **そして、最初に作られた運動が `greeting` なのは、そのためである。**

## 1つの運動

`motions/greeting.json`——意図であり、存在している唯一のものである:

| 語 | 自由度 | 量 | 時間 | 組 |
|---|---|---|---|---|
| `small forward tilt` | `pitch` | `+40` カウント（512 → 552） | 600 ms | 0 |
| `return` | `pitch` | 512 | 600 ms | 1 |

⚠️ **語は、ファイルの中に無い。** `schemas/motion-intent.schema.json` が `additionalProperties: false` を定めているので、
**入れる欄が無い**——**ゆえに置き場は `motion.py` である。** ⛔ **これは不便ではない。`Intent` は既にカウントであり、
「なぜその数なのか」を自分では言えない。** **語と数を対にした行は、`references/README.md` に在る。**

⛔ **語は概念文書 §5 から来た。数はどこからも来ていない**——`demo_rig()` が、
渡している数を全部並べ、**それぞれが何でないか**を書いている。
⚠️ **とくに、速度上限を1つも渡していない**ので、段差の検査は鳴らない——
**この走行で実際に効いているのは枠（190〜833）であり、それが唯一の実測である。** **緑の走行を「安全」と読まないこと。**

## 走らせる

リポジトリの根から:

```
python3 -m projects.pet                # 5つを順に回す。Ctrl-C まで
python3 -m projects.pet --state sleepy # 1つ出して終わる
python3 -m projects.pet --sync         # 同期更新を使って
python3 -m projects.pet --motion greeting  # 運動を走らせ、顔を同じ時計から出す
```

⚠️ **`--sync` の既定は「使わない」であり、これは意図である。**
**目の前の端末が `CSI ? 2026 h`/`l` を実装しているかは、この工房の側からは測っていない。**
**測っていない前提は、端末に触る唯一の場所の既定にはならない。**

⚠️ **`--motion` の送り先は Mock であり、最後の行がそう言う**——**あわせて、どの検査が鳴らなかったかも言う。**
**0が4つ並んだ走行は、「何も拒否されなかった」走行である。機体について何かが確かめられた走行ではない。**

## 検査されていること

**`tests/` が、このディレクトリについて7つを主張している**——4ファイルで、他の試験と一緒に走る:

- **1フレームは1回の write**——**そしてこれは速さの話ではなく、安全の話である。**
  `frame()` は同期更新の開始と終了を**同じ文字列の中に**返すので、
  1回だけ書く呼び手が対を開いたままにすることはできない。
  **`close()` が出す2回目の `SYNC_END` は、write が途中で切れた場合の救助であり、冪等である。**
- **フレームの形が、状態によって変わらない**——箱は5つとも8列×4行なので、
  描き直しのときに前のフレームの行が残らない。
- **1列より広い文字が無い**——**この工房の文書は CJK である。**
  顔に全角が1文字混じれば、**画面上で図がずれるのに `len()` は何も言わない。**
- **`projects/` は、変わってしまうものを import しない**——`engine/` と同じ禁止一覧を、
  `tools/purity.py` から使う。⛔ **`__main__.py` は除外一覧に名指しされており、除外そのものが検査されている**
  ——**入口は、このリポジトリが `time` を import してよい唯一の場所である。
  ループは時計を呼ぶ側から受け取るからである。**
- **顔と身体が、同じ刻みから出る**——`Take.drawn_at` が `ticks[0].started` と一致する。
  ⛔ **顔は最初の刻みの中で描かれ、ループの前では決して描かれない**——**外で描けば、
  *1つの時計*は主張ではなく説明になり、検査するものが何も残らない。**
- **Pet は、意図の2組目が言う場所へ戻る**——**そして、2組の境目で何も飛ばない。**
  ⚠️ **後半は 2026-09-28 に足された。それが捕まえたはずの欠陥の後である**:
  **演技が終わったとき、組は最後の組へ戻されていたが、*offset* は戻されていなかった**——
  **ゆえに終わった後の刻みが、最後の組の*最初の*標本を送っていた。** **`HISTORY.md` の 0.5.0 を見よ。**
- ⛔ **意図が書かれていない開始位置から走らせると、Pet はそこから離れる。**
  **これは欠陥ではなく、型の限界の記録である。** `target` は絶対カウントなので、
  **意図は機体がどこに居るかを知らない**——512 のために書かれた意図を 400 から走らせると、
  **Pet は自分のいた場所ではなく 512 へ行く**——**そして門は1つも止めない。1フレーム1フレームが、どれも合法だからである。**
  **間違っているのは意味のほうである。** **決定論的な核心は、その数が意味を持つかを知らない。**

⚠️ **最後の1つは、このディレクトリを `engine/` と同じ強さにはしない。** 見ているのは import だけである
——**そして上の主張は、Mock についてのものである。**

## ここに無いもの

- **シリアル層が無い。** Mock は制御箱のふりをした Python のオブジェクトであり、**フレームはそれより先へ行かない。**
  ⛔ **機体が握っているのは、この1層だけである**——**そして、Mock と実機が最も食い違う場所でもある。**
- **運動は1つ、動詞は5つのうち1つ。** ⚠️ **語彙の5つの動詞のうち3つは、この機体が持たない並進を指している**
  ——**ゆえにまだ1つも、D-12 が `references/` に足した欄を鳴らしていない。**
- **LLM が無い。** いつどこで変わるかは、上の決定 C に在る。
- **フィードバックが無い。** 開始位置は手で渡す——**`demo_rig()` が、その数がどれであり、測定でないことを書いている。**
  **機体は、自分が何をしたかを報告してこない。**
