# projects/pet/ — 画面

**`projects/` に住む最初のものであり、Pet のうちで存在している唯一の部分である。**

⛔ **これは顔であり、それ以外ではない。** 運動はここへ届かない——**決定論的な核心は軌道を計算するが、
その計算をこの画面へ繋ぐものが、まだ1つも無い。** **Pet の身体は `engine/` に在り、顔はここに在る。
そして2つは、まだ時計を共有していない**——**「顔と身体は一つの時計から」は、
設計ノートが書いている規則であり、下の決定がこのディレクトリをリポジトリの内側に置いた理由である。**

## 記録されている決定が2つある

- **A — 顔を保ち、「猫」と名乗る**（2026-09-28、著者）。`expressions.py` の5つの顔は、
  **概念文書 §5 から逐語で写した**——**1文字も変えていない。字下げも含めて。**
  変わったのは図ではなく記録である。**なぜ名を書くことが決定そのものなのかは `expressions.py` に在る**
  ——**動物の形を禁じた論は「この ASCII は抽象的である」を前提にしており、`/\_/\` は猫の耳である。**
- **C — Pet はこのリポジトリの内側、`projects/` の下に住む**（2026-09-28、著者）。
  ⚠️ **これは推奨に反して決まった。** 示された代価は `CLAUDE.md` の固定方針への但し書きであり、
  **その但し書きはまだ払われていない**——**`projects/` の下で LLM を呼ぶ最初のファイルと同じコミットで入る。**
  **このディレクトリに、そのファイルは無い。顔は決定論的である。**

## 5つの顔

| 状態 | 顔 | 概念文書が組み合わせている運動 |
|---|---|---|
| `happy` | `( ^.^ )` | small bounce → small bounce → settle |
| `sleepy` | `( -.- )` ＋4行目 `z` | slow downward movement → small sway → still |
| `angry` | `( >.< )` | quick tilt → hold → small corrective movement |
| `curious` | `( o.o )` | small left tilt → center → small right tilt |
| `greeting` | `( ^.^ )` | small forward tilt → return |

⚠️ **最後の行は書き間違いではない。`happy` と `greeting` は同じ顔である。**
**同じ表情ではない**——**2つを分けているのは運動だけであり、それ以外に何も無い。**
**これは主張ではなく実測である**（`tests/test_pet_expressions.py`）。
⇒ **身体を落とせば、この2つの状態は1つになる。** **「顔と身体は一つの時計から」は
様式の好みではない——この5つの図から出てくる。**

## 走らせる

リポジトリの根から:

```
python3 -m projects.pet                # 5つを順に回す。Ctrl-C まで
python3 -m projects.pet --state sleepy # 1つ出して終わる
python3 -m projects.pet --sync         # 同期更新を使って
```

⚠️ **`--sync` の既定は「使わない」であり、これは意図である。**
**目の前の端末が `CSI ? 2026 h`/`l` を実装しているかは、この工房の側からは測っていない。**
**測っていない前提は、端末に触る唯一の場所の既定にはならない。**

## 検査されていること

**`tests/` が、このディレクトリについて4つを主張している**——3ファイルで、他の試験と一緒に走る:

- **1フレームは1回の write**——**そしてこれは速さの話ではなく、安全の話である。**
  `frame()` は同期更新の開始と終了を**同じ文字列の中に**返すので、
  1回だけ書く呼び手が対を開いたままにすることはできない。
  **`close()` が出す2回目の `SYNC_END` は、write が途中で切れた場合の救助であり、冪等である。**
- **フレームの形が、状態によって変わらない**——箱は5つとも8列×4行なので、
  描き直しのときに前のフレームの行が残らない。
- **1列より広い文字が無い**——**この工房の文書は CJK である。**
  顔に全角が1文字混じれば、**画面上で図がずれるのに `len()` は何も言わない。**
- **`projects/` は、変わってしまうものを import しない**——`engine/` と同じ禁止一覧を、
  `tools/purity.py` から使う。⛔ **`__main__.py` は除外一覧に名指しされており、除外そのものが検査されている**
  ——**入口は、このリポジトリが `time` を import してよい唯一の場所である。
  ループは時計を呼ぶ側から受け取るからである。**

⚠️ **最後の1つは、このディレクトリを `engine/` と同じ強さにはしない。** 見ているのは import だけである。

## ここに無いもの

- **運動が無い。** `engine/` が計算する。**2つを繋ぐものが無い。**
- **身体と共有する時計が無い。** 画面は状態を描く。**動かしはしない。**
- **LLM が無い。** いつどこで変わるかは、上の決定 C に在る。
