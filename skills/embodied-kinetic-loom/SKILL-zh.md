# embodied-kinetic-loom —— 写出 Motion Intent

**这个技能写出这台引擎所围绕的那唯一的值。** 那个值上游的一切都可以是自由的——一个判断、一场对话、房间里的一个人。**那个值下游的一切都是函数。****这个技能就是上游的那一端。**

⚠️ **这是一份文档，不是一个程序。** 它指示一个会话。 ⛔ **本仓库的代码不调用模型**——写的是会话中的 Claude，**而这份文件就是它的指引。** 那就是决定 D-03，**也正是它下面的轨迹能够被精确检查的原因。**

## 这个技能是什么

- **它是唯一的写者。** ⛔ **不是「本仓库里的写者」——是写者。** 当没有会话、而 Pet 开着的时候，**应用里的 AI 来写意图**（决定 C）。**而它是照着这份文件写的。** 规格一份，调用者两个。**一个技能就够，理由就在这里。**
- **它的产物是一个 `Motion Intent`**——机器三个自由度上的、以计数和毫秒写成的小 JSON。
- **它的词的来源是 `references/README.md`**——语汇。**写任何东西之前，先读它。**

## ⛔ 在第一个运动之前，读这一段

**输出不是一个文件。** 文件可以重渲染、重剪辑、删除。**运动在房间里发生一次，无法撤回。**

- **机器不检查它收到的值。** 夹到合法值域是主机的工作——**厂商自己的参考代码就是这么写的。**
- **协议里没有停止命令。** `[mo0]` 的意思是*停止报告*，`[sav]` 是写进 EEPROM。 ⛔ **两者都不停电机。**
- **上游固件没有软启动，也没有软停止。** 阶跃指令就作为阶跃到达。**引擎的轨迹正是为了避免这件事而存在，这个技能不得把它破坏掉。**
- **只有主机能让机器停住。** 一旦停止发送，十五秒内扭矩掉到约四分之一——**而电机并不停止。**
- **三个轴中有一个进入强制停止，另外两个也不再能操作。**

⚠️ **这些不是关于这个技能的注意事项。** 它们是决定论核心存在的理由。**连同测量一起，写在 `CLAUDE.md` 里。**

## 步骤

### 1. 取词

**读 `references/README.md`。** 那张表就是语汇——词、机器拥有的自由度、量、时间，以及 ⛔ **这台机器覆盖不了的差的那一栏**。

**用名字取这个运动需要的词。** ⛔ **不要在脑子里把它们换成数，然后写下那些数。** 数来自那一行——不是来自对*缓慢*意味着什么的感觉。

### 2. 当词不在表里

⛔ **不在表里的词，就不在语汇里。** **不要在写意图的那一刻造词。**

**先写的是那一行**——写进 `references/README.md` **和它的两本镜像，同一个提交**——并且把每一栏都填上，**包括差的那一栏。** 当一个词指的是机器没有的自由度时，**那一栏就是陈述这段距离的地方，也正是那一栏存在的理由。**

**意图后写。** ⚠️ **语汇生长的路只有这一条，而这是刻意的**——**一行要付出一栏必须诚实填写的代价。**

### 3. 写意图

**形状由 `schemas/motion-intent.schema.json` 定下**——一个对象、一个键、一个运动的数组：

```json
{
  "moves": [
    { "dof": "pitch", "target": 552, "duration_ms": 600, "group": 0 },
    { "dof": "pitch", "target": 512, "duration_ms": 600, "group": 1 }
  ]
}
```

- **`dof` 是 `pitch` / `roll` / `yaw` 之一。** ⚠️ **这三个名字是我们的，不是机器的**——**控制箱没有记录任何正准的轴对应，而每个轴的符号取决于接线。**
- **`target` 是计数**，协议自己的单位。 ⛔ **可到达的值域是刻意不放进类型里的。** 默认情况下主机只能指令 190〜833，**而箱子的限位是反馈驱动的，不是常量。** **外壳在运行时给出——不要把值域写进意图再相信它。**
- **`duration_ms`** 是这个运动花的时间。**共享同一个 `group` 的运动同时运行**，一个群里的每个运动必须有相同的长度，**而群从零开始按升序运行。**
- ⛔ **词不会被写进意图。** 模式是关闭的，**而关闭是对的。** **意图已经是计数，它说不出为什么是这个数**——**把两者放在一起的地方，只有 `references/README.md`。**
- **`quality` 是唯一留着打开的一栏，而引擎忽略它。** 在那里写什么都改变不了运行的东西。**它留着打开，是因为本该填它的那半个映射还不存在**——副词。

**放在哪里：`projects/<作品>/motions/<名>.json`。** `projects/` 是本仓库里放工作与记录的唯一地方。

### 4. 跑它，并跑检查

```bash
python3 -m projects.pet --motion <名>     # 脸与身体，来自同一个时钟
python3 -m pytest tests/ -q               # 检查了什么、在哪里，见 tests/README.md
python3 tools/check_vocabulary.py         # 那张表——列、自由度、路径
python3 tools/check_i18n.py               # 镜像——包括刚加的那一行
claude plugin validate --strict .         # 只在碰了 .claude-plugin/ 的时候
```

⛔ **`--motion` 的送信对象是 Mock，不是机器。** 串口层是机器握着的唯一部分，**它还没有被写。**

## 这个技能不得做的事

- ⛔ **造词。** 见 §2。
- ⛔ **把词写进意图。** 模式会拒绝它们，**而模式是对的。**
- ⛔ **陈述值域。** 安全外壳属于运行时的主机。
- ⛔ **事后照着已经发出去的写那一行。** 那一行是刻意先写的。
- ⛔ **够到机器。** 本仓库里没有任何东西打开端口。

## 这个技能做不到的事

**说出这个运动对不对。** 机制可以检查。**目标不能。** ⚠️ **一片绿只意味着机制算出了它被告知要算的东西**——仅此而已。**那条线在 `docs/verification-boundary.md` 里被论证。**

⛔ **而映射本身没有检查。** `tools/check_vocabulary.py` 读的是那张表的形状，**不是它的真伪。** **经过写者判断的那一个往返，是唯一没有检查的一步。**
