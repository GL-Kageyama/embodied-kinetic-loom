# tests/

**15 个文件、160 项测试，全部通过——实测 2026-09-27。**

**本文件曾经写着「一项也没有」。** **它与第一个测试在同一次提交里改变**——**那正是 `CLAUDE.md` 那一节所规定、而这个目录所维护的规则。**

## 五项检查，以及各自的住处

| # | 检查 | 住处 | ⚠️ 同时记录下来的东西 |
|---|---|---|---|
| **1** | 两端——位置、速度、加速度在两端为零 | `test_profile.py`, `test_plan.py` | ⛔ **梯形过不去这一项**——两端加速度不为零 |
| **2** | 不超限——逐轴**与合成** | `test_limits.py`, `test_gate.py` | ⛔ **梯形也过不去这一项**——角点上加加速度无定义。**而且这项检查跑两遍，在两个不同的时刻**——见下 |
| **3** | 可达性——会消失的区段 | `test_profile.py`, `test_admit.py` | **异类：它处理的是并不存在正确轨迹的情形** |
| **4** | 决定论 | `test_plan.py`, `test_purity.py` | 只跑两遍来比较是不够的——见下 |
| **5** | Safety 拒绝它该拒绝的 | `test_admit.py`, `test_gate.py` | ⚠️ **计划时的一侧与运行时的一侧，是两项不同的检查，不是同一项的两次抄写** |

**五项之中有两项是否定性的主张，而那正是要点。** **回退被写成回退；这些测试记录下「选择它等于关掉一项检查」。** **若没有它们，那一项会悄悄消失。**

## 同一项检查，在两个时刻

**限制在计划时（`admit.py`）被检查，也在每一帧离开时（`backend/gate.py`）被再检查一次。第二次不是第一次的重复。**

计划时握着整条轨迹，没有时钟。门握着一帧，以及**在循环里实测算出的经过时间**。**有三样东西只在第二次存在**: **相邻两帧之间的间隔**——既然固件没有软启动，正是它决定一条指令是否成为落差——、**送出的时刻**，以及**某个自由度去哪个电机**。

⚠️ **而两者会在要紧的方向上不一致。** 通过了 `admit` 的轨迹，**仍可能在门那里造出落差**——**因为有一个刻点迟到，发送就会跳过采样。** **那种情形由 `test_backend.py` 断言，而且它不掩盖、直接报出自己的限界**——见下。

## `05 §2.2` 说「写不出来」的那项检查

**设计笔记列举了周期可被检查的两种方式，两者都是形状而非性质**——**「以截止方式书写」**，以及**「不要每次都调用 `sleep(period)`」**。⛔ **两者都还没被写出来，因为还没有可写的循环。**

**`test_cycle.py` 把它们写成性质。** 循环从调用方接收时钟——`engine/` 不得 import `time`——**于是假时钟跑起这个循环，并数出被要求睡去的量。** 两项形状检查变成: **即使每一次 sleep 都睡过头，第 `n` 个刻点的截止仍是 `start + n * period`**，以及 **单次 sleep 的请求不超过 `period × sleep_fraction`**。

⚠️ **`grep` 看得见那一行在源码里。它看不见那一行跑起来时是否成立**——**一个每次都睡 `deadline - now` 的循环，一个 `sleep(period)` 的字样都不含，行为却和写了它一模一样。**

## 不属于那五项的一项检查

**`test_intent.py` 从两侧按住边界。** **类型的 `quality` 栏位，模式接受它、代码无视它**——**而且两半都被断言了，因为只有一半的话，边界就会塌掉。** **词汇表落地的那一天，后一半会被改写，而不是被删除。**

## 为什么决定论要静态地看

**`test_purity.py` 读取 `engine/` 下每个文件的 import，其中若有 `random`、`time`、`os`、`socket` 或 LLM 客户端，就会失败。**

**把同一个输入跑两遍再比较，并不是证明。** **那两遍可能只是碰巧一致。** **该看的是 import；而 AST 会在 grep 只找到文档字符串里那个词的地方，找到它们。**

## 被记录而不是被修掉的限界

**门拒绝一帧时，会保住最后放行的那一组——因为*不发送*不是*停下*。于是一个迟到的刻点就能冻住一根轴，而门里没有任何东西把它带回来。**

原因是门的基准是*它最后放行的值*，而发送器提议的是*墙上时钟的值*。**提议会一直往前跑，所以差距永不闭合。** **机体被保住了——那是安全的方向——而没有到达，那不是这个机构的目的。**

**`test_a_late_tick_freezes_the_axis_and_the_gate_does_not_recover` 记录了这一点，并列出了三个选项。** 它被写成**限界**而不是设计——**选择是作者的**——而在选定之前，行为被断言着，**好让改变不会无声地发生。**

## 支撑这个目录的规则——**适用于我们自己**

**`CLAUDE.md` 的 Tests 节，不得在磁盘上已有测试文件的情况下写着「还没有」。**

**那不是假设**——**有一个姊妹仓库现在就是如此**——**磁盘上有 7 个文件、54 个测试，而它的 `CLAUDE.md` 至今仍写着「尚未整备」。** **因此在这里，第一个测试落地时，那一节在同一次提交里改变了。** **一节若是在描述目录而不是读取目录，就是这样产生的。**
