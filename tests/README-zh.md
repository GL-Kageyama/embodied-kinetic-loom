# tests/

**8 个文件、80 项测试，全部通过——实测 2026-09-27。**

**本文件曾经写着「一项也没有」。** **它与第一个测试在同一次提交里改变**——**那正是 `CLAUDE.md` 那一节所规定、而这个目录所维护的规则。**

## 五项检查，以及各自的住处

| # | 检查 | 住处 | ⚠️ 同时记录下来的东西 |
|---|---|---|---|
| **1** | 两端——位置、速度、加速度在两端为零 | `test_profile.py`, `test_plan.py` | ⛔ **梯形过不去这一项**——两端加速度不为零 |
| **2** | 不超限——逐轴**与合成** | `test_limits.py` | ⛔ **梯形也过不去这一项**——角点上加加速度无定义 |
| **3** | 可达性——会消失的区段 | `test_profile.py`, `test_admit.py` | **异类：它处理的是并不存在正确轨迹的情形** |
| **4** | 决定论 | `test_plan.py`, `test_purity.py` | 只跑两遍来比较是不够的——见下 |
| **5** | Safety 拒绝它该拒绝的 | `test_admit.py` | ⚠️ **只限计划时那一侧。** 运行时的关卡还不存在 |

**五项之中有两项是否定性的主张，而那正是要点。** **回退被写成回退；这些测试记录下「选择它等于关掉一项检查」。** **若没有它们，那一项会悄悄消失。**

## 不属于那五项的一项检查

**`test_intent.py` 从两侧按住边界。** **类型的 `quality` 栏位，模式接受它、代码无视它**——**而且两半都被断言了，因为只有一半的话，边界就会塌掉。** **词汇表落地的那一天，后一半会被改写，而不是被删除。**

## 为什么决定论要静态地看

**`test_purity.py` 读取 `engine/` 下每个文件的 import，其中若有 `random`、`time`、`os`、`socket` 或 LLM 客户端，就会失败。**

**把同一个输入跑两遍再比较，并不是证明。** **那两遍可能只是碰巧一致。** **该看的是 import；而 AST 会在 grep 只找到文档字符串里那个词的地方，找到它们。**

## 支撑这个目录的规则——**适用于我们自己**

**`CLAUDE.md` 的 Tests 节，不得在磁盘上已有测试文件的情况下写着「还没有」。**

**那不是假设**——**有一个姊妹仓库现在就是如此**——**磁盘上有 7 个文件、54 个测试，而它的 `CLAUDE.md` 至今仍写着「尚未整备」。** **因此在这里，第一个测试落地时，那一节在同一次提交里改变了。** **一节若是在描述目录而不是读取目录，就是这样产生的。**

## 今天被检验的东西，以及它们在哪里

**不是测试的那两项检查，不在这里。**
